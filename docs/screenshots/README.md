# Screenshots

此目录保存通过浏览器拍摄的实际页面截图。目前没有作为正式展示的已审核截图，根 README 不嵌入占位图片、生成图片或虚构研究结果。

建议完成本地真实研究后拍摄：

| 文件 | 页面与内容 |
| --- | --- |
| `dashboard.png` | 问题输入、最近历史 Run。 |
| `run-progress.png` | 运行中 Task、依赖、阶段和 SSE 时间线。 |
| `report.png` | 已保存报告、编号 Citation 与 References。 |
| `evidence-explorer.png` | Claim → Evidence → Source、验证/相关性状态。 |

推荐 1440×1000 或更大桌面视口。若使用 Mock 数据，截图说明必须标注为离线测试。既有自动化截图在未提交的 `workspace/validations/phase8c/`，属于离线测试记录，不冒充真实研究成效。

审核后可在根 README 添加 `![Research progress](docs/screenshots/run-progress.png)`。请只引用实际存在的图片。
